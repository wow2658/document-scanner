## 4. 규칙 기반의 한계
본 스캐너가 사용한 규칙(가정):
1. 문서는 화면에서 가장 큰(혹은 충분히 큰) 밝은 사각형이다.
2. 문서의 외곽은 4개의 직선 변으로 근사된다(`approxPolyDP` 꼭짓점 4개).
3. 문서는 배경과 밝기 대비가 뚜렷하다.

각 규칙이 깨지는 상황:
1. → [복잡한 배경에 더 큰 사각형 물체가 있을 때]
2. → [종이가 구겨져 변이 곡선일 때 / 모서리가 가려졌을 때]
3. → [그림자·조명 얼룩으로 문서-배경 경계가 흐릿할 때]

"규칙을 추가하면 해결되는가?": [경험 서술 — 규칙을 더할수록 특정 케이스는 잡지만 다른 케이스에서 새 예외가 생겨 유지보수가 급격히 어려워졌다.]

## 5. 학습 기반 접근이 필요한 이유
- 규칙 기반은 "밝기/면적/꼭짓점 수" 같은 사람이 정의한 저수준 단서에만 의존한다.
- 데이터에서 학습하는 방식(가설): 다양한 조명·각도·배경·구겨짐이 포함된 라벨 데이터로
  "문서의 외형 자체"를 학습하면, 명시적 임계값 없이도 경계가 흐릿하거나 변이 곡선인 경우까지
  일반화해 검출할 수 있을 것이다(예: 세그멘테이션/코너 회귀 모델).
- 결론: 환경 변동이 큰 실제 입력에서는 고정 규칙의 조합보다 데이터 기반 학습이 일반화에 유리하다.
